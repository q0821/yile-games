## 授權與範圍
使用者確認網頁死活練習是獨立、免費、無廣告、不導購的學習功能，iOS 不含死活。依官方 CC BY-NC-SA 4.0 匯入 easy 的 140 題，保留原始 SGF、LICENSE、README、上游提交與每檔 SHA-256。翻譯／改作內容依相同授權分享，畫面提供作者、來源、原檔與授權連結。

## 決策及理由
- 使用完整 SGF 變化樹，否決繼續用 SOL 第一手配對，因原檔同時包含正確及錯誤分支，多手後才有結論。
- 重用圍棋規則處理提子、自殺與劫；不新增 AI 依賴。否決以 KataGo 估計代替作者解答，因兩者不是相同證據。
- 原文解說完整保留並標明英文，不批次猜譯或偽造題目目標。介面及解題狀態使用繁體中文；後續若翻譯，需逐條校對及標示改作。
- 只在走到作者明示 Correct 或 Also correct 的結論時記錄「本次變化完成」。不把所有變化都無條件當正解，也不宣稱走完全部可能應手。原譜部分參考分支沒有正誤標記，自動應手優先採能通往明示正解的分支，其他原譜仍可逐手檢視。未收錄落點顯示未收錄，不斷言必定錯；已收錄錯誤分支可逐手查看反駁。
- 題庫與進度使用獨立 ggg 命名，不覆寫舊 3,908 題來源或進度。舊 /tsumego/ 題庫網址維持阻擋，新內容使用 /go-problems/ggg/。
- 每段完成後提交推送依使用者授權；不手動部署、不寄信、不新增 iOS 功能、不匯入中高階 280 題、不改原等級或付款。
