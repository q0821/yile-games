# 網頁入門練習第二階段

## 範圍與理由
使用者於 2026-09-22 同意繼續，並要求重新上網尋找可用題庫。

選擇暫停新版網頁提供舊死活內容，保留原始資料供授權盤點與舊進度。否決只隱藏首頁入口，因為直接網址及快取仍可取得題目。建置時剝除本次生成的題庫副本；不刪除來源檔或使用者資料。新版 Service Worker 啟用後阻擋舊題庫請求，無法回收已下載或未更新的舊版。

原創課程新增連接、阻止連接、吃子救棋各三題，以規則逐題驗證。阻止連接僅指佔住兩串棋目前共用的直接連接點，不宣稱永久切斷或殺棋。否決直接使用外部大量題庫，原因是授權與解答品質必須先確認。

進度使用獨立的本機儲存鍵與穩定題目 ID，保存已自行解出、待複習與上次題目。錯答或看解說加入複習，當次再試答對不清除；另開一次題目、不看解說且第一次答對才清除。看過解答後的練習標示為跟著解答完成，不冒充自行解出。重新整理後重新呈現原盤面，不保存半完成棋形。保留題目紀錄中的提示／錯答狀態，避免重新整理洗掉當次紀錄。

## 不包含
不新增 iPhone 功能、不調整既有等級、不新增服務或套件、不取得帳號資料、不跨裝置同步、不寄信、不手動部署。初始驗收未推送；使用者後續明確授權每完成一段 commit 與 push。不修改舊題庫進度。真人校準需邀請初學者實際試玩，本次不宣稱完成。

使用者後續確認非商業營運前提，Go Game Guru 列為下一批優先候選，詳見授權盤點。完整 SGF 變化樹整合不與本輪原創單手練習混做，因判定模型不同。
