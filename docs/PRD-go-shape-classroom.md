# 棋形教室規劃與驗收

## 目標與範圍

2026-09-23 使用者授權規劃後執行。網頁圍棋入門新增四單元、18 主題，每主題提供白話介紹、手動分步圖解、兩題小練習及答後解說。原有 21 題基礎練習保留，新增獨立入口「棋形教室」，沿用棋盤、座標、棋子與無裝飾側框的回饋樣式。

不新增 iOS 功能，不改 GGG 題庫、既有 21 題判定或進度鍵，不新增套件、帳號、付款、後台、資料庫、對外訊息及手動部署。提交與推送沿用既有每段收尾授權，自動部署需另行驗證。

## 課程

1. 認識棋盤：星位、天元、三三。以 19 路盤解說，座標略過 I。
2. 基本棋形：長、立、跳、尖、飛、虎口。說明相鄰、間隔與方向，避免把斜角當成已連接。
3. 吃子技巧：抱吃、門吃、雙叫吃、征子、枷吃、倒撲。展示合法局部變化；征子提醒引征，門吃與枷吃的名稱有重疊，依示例說明，不宣稱互斥分類。
4. 基本死活：眼、真眼與假眼、兩眼活棋。強調單眼不保證活棋，兩個空點不一定是兩眼。

每主題一題看圖選擇、另一題理解確認。吃子練習只檢查本題指定目標與示範手，不聲稱窮舉所有正解或完整實戰棋力。採用選項作答，讓 19 路盤手機畫面不需精準點擊小交叉點。示範由使用者逐步前進，不自動播放。

## 資料與判定決策

教學局面、文字與選項自行編寫，不下載或轉錄外部題庫圖片或棋譜。第一手教學資料只作術語及規則查證，來源列於下方。示範中實際落子全部使用現有規則引擎，非法步驟報錯並顯示無法載入，禁止用假盤面補位。靜態棋形圖解與實戰交替落子明確分開。

新進度使用獨立鍵與穩定題目 ID。保存目前主題、題目、錯答與提示狀態；看答案不計自行解出，錯答後答對仍列待複習。重新整理不清除提示狀態；不覆寫損壞或未知版本資料，儲存失敗顯示訊息並記錄無個資的警告。新課程進度與舊練習分開，避免原有已完成數量被重算。
