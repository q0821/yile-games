# 網頁圍棋入門體驗

## 範圍
本次新增網頁入門陪練、新手設定、數氣／一手吃子／逃出叫吃三種練習。初始實作階段不部署、不推送；2026-09-22 使用者指示「收尾」後授權 commit 與 push。不增加 iOS 功能、不更動付費規則、不改既有等級進度、不新增套件或外部服務。

## 決策與理由
- 採獨立陪練模式，保留原 13 級。否決直接改低階等級，因既有等級涉及使用者進度，且 KataGo 的低搜尋量仍有最低值限制。
- 陪練只看單步吃子、救棋與連接，混合一般合法落點，不讀取 KataGo 候選手。否決只放寬容許失分，因候選池若全是好手便不能有效變弱。保留合法手、自殺、劫檢查與不填明顯己方眼的基本限制。不標示未校準的棋力級位。
- 陪練不升降原本等級，因教學局與一般對局難度不可直接比較。
- 新手設定只先填設定，玩家按開始新遊戲才生效，沿用進行中對局確認，避免覆蓋棋局。
- 三類題各提供四個原創局面，正解由規則計算，不以 AI 臆測教學答案。數氣共用氣只算一次；逃出叫吃表示本手脫離一口氣，不保證整串永遠活棋。
- 練習採可用鍵盤操作的棋盤交叉點按鈕，重用規則模組；無須載入 AI 模型。先提供短課程，否決大量自動生成題，因題目教學品質需逐題校驗。
- iOS 排除新入口及練習路由，原對弈模式保持原行為；共享狀態新增欄位對舊存檔預設關閉。

- 授權盤點後暫緩新增死活導流，原因是既有題庫再散布授權未確認；保留既有入口與檔案，待使用者決定處理方式。詳見 `TSUMEGO-LICENSE-AUDIT.md`。

## 不適用項目
資料庫、後台、付款權限、寄信、跨服務副作用、時區、外部 URL 與新增套件均不涉及。本功能只使用內建題目與本機對局狀態。
